## 1. Open work, in priority order

### 1a. Minax does nothing in the engine — one line, fully specified

`engine/src/game/ai.c`, gated (castle) sweep:

```c
if (role == 0 || (role & 0x80)) continue;
```

Minax is `role == 0` in a castle, so the engine skips her entirely: she never moves, never
rolls a special, never strikes. The original routes role 0 into `asm/1040_minax_proximity_check`
— test `mon_type == 0x40`, then `abs(dx) < 4 && abs(dy) < 4`, then `asm/0F8E_combat_minax_attack`
which prints `MINAX CRIES: DIE FOOL!` and subtracts one from the **high** byte of the HP pair
(exactly 100 HP, borrow = death). `asm/1040` is reached from `asm/218b`, the **no-move tail**, so
she strikes without moving.

Same line explains why the owner saw no arms paralysis and no sleep in the engine: in a castle
`casts = (role == 1)`, so nothing else rolls either.

Full spec, and the gate's control, in **`docs/cp8-minax-gaps.md` § 1**. The control is the part
not to skip: a player five cells away must be untouched, or the `< 4` window is decorative.

### 1b. Minax's teleport on being hit — observed, NOT decoded

She teleports between the **north-east and south-west chambers** on every hit. This is the
walkthrough claim in `docs/goal-spec.md` § 1, upgraded from recalled to observed tonight. **No
address is known.** Do not guess a destination; the frames are the evidence and the trace window

### 1c. Invulnerable creatures — the mechanism is unknown and the engine has none

The owner verified that castle creatures took no damage across repeated attacks. Recorded as
`docs/needs-gameplay.md` **G78** with three candidate mechanisms in test order. The first is a
trap: the 32-slot arrays at `DS:137/157/177/197` are the **world-map** table and site occupants
use a different encoding, so reading them and finding nothing near the player proves nothing.
The recipe that works: attack once, diff the whole 64 KiB DS read for changed bytes — a refused
damage changes nothing, and the absence is the answer.

**Consequence:** the engine has no invulnerability of any kind, so it is wrong in a way no
existing test can see. And the goal spec's policy layer needs a "do not keep attacking this"
rule it cannot currently express.

### 1d. The engine's ending is not the ending

`engine/src/game/victory.c` has the state writes and the text but **neither the fade nor the
flight**, and the renderer drew the rocket mode byte as if it were the avatar — so the player
appeared to turn into a rocket standing in a chamber. The original: print the two death lines,

iteration — 64 renders), then set `DS:13 = 0x28` (rocket *mode*, not a transformation), then the
flight loop, then `YOU HAVE SAVED THE UNIVERSE, AND COMPLETED ULTIMA ][!`.

### 1e. `cmd_E` signpost arm — evidence in hand, never built

Pressing `E` on a signpost prints, on the CMD line, `ENTER-THE SIGN READS:` and on the next line
the era: `ANOS: LEGENDS!`. **Captured on frame from the original** this session; it matches the
static decode (`asm/3389` → the `v == 10` arm → `asm/3525` → `asm/353A` → `asm/3546`) including
the leading dash on `-THE SIGN READS:` and the `0x0d` that puts the era on the next line.

The engine's `site_for_tile()` handles `tile >> 2` cases 5..9 and `default: return 0`, so a
signpost (art `0A`, tile `0x28`) takes the no-door path. Neither string is in the extractor's
`STRINGS` table, so they go there first — the extractor is the only writer of `gen_content.h`.
Plan agreed and not executed: add both string groups, add `case 10:`, gate on the visible
two-line output, and open a `needs-gameplay` item for what a sign says **off Earth**, where
`DS:49` is a world index and the dispatch has no proven arm past 4.

## 2. Facts worth knowing cold

- **`NEGATE TIME` = one strange coin, 20 turns, everywhere.** `asm/3C04` spends
  `items_held[13]` (STRANGE COIN, `DS:E3`) and sets `DS:26A = 0x14`; `asm/2199` refuses every
  step while it is non-zero; `asm/0C5B` decays it one per handled input event. Confirmed live:
  `E3 09 → 08 → 07`, `26A` read `0x0F` a few commands later. It works **indoors** because the
  check is in the step gate, not the sweep — `docs/contract-creature-tick.md` § 5b already said
  "every species, every tile" and was right when I was not.
- **Resist items:** legs → BOOTS `DS:D9`, arms → CLOAK `DS:DA`, sleep → GREEN IDOL `DS:E4`,
  each a ~75% resist, **not immunity**. Magic missile (`0xF8`) has **no resist at all**.
- **Any weapon harms Minax.** The phaser took her 199 → 33 → dead. `docs/goal-spec.md` W2's
  quicksword edge is refuted as a *requirement*; weaker weapons just take longer.
- **`ExecutedInstructions` in the noVNC container is a rolling window of ~2,200–2,600 game
  instructions** and rolls past a one-shot event in seconds. Dumping "immediately" does not fix
  it. For a one-shot, read the memory the event writes over the MCP endpoint. This is written
  into `docs/spice86-capture.md` next to the tool row that invites the mistake.
- **`mapx`/`monx` are 4224 / 384 bytes and the grid origin is offset 0**, with the extra 128
  bytes a tail, not a header. Proven by the era-0 moongate cells `(29,56)(31,56)(33,56)(35,56)`,
  which are walkable grass at offset 0 and impassable mountain at offset 128.
- **The engine writes the save record on site entry only.** A save can be a dozen sectors behind
  where the player is standing. This bit me repeatedly tonight.

## 4. Hazards that cost time tonight, so you don't pay them again

1. **Do not restart the owner's container without being asked.** It reloads the save and destroys
   the live session. This happened twice and both times it was my initiative, not his.
2. **Do not inject keystrokes into his session.** `spice86_type.py --keys` opened his
   ready-weapon menu mid-play. If you need a frame, ask him to press the key and say "now".
3. **A stale artifact looks exactly like a live one.** I read a stale save and called the sector
   wrong, and compared two frames with no turns between them and called the creatures frozen.
   Both were confident and both were wrong.
4. **`--debug cli` writes nothing in headless**, and `WAIT` in a script is not a turn — a run of
   `WAIT`s takes zero turns, so "nothing moved" measured nothing. Use `--auto-pass-polls N` to
   make idle turns exist.
5. **`pkill -f <scriptname>` kills your own shell** when the pattern appears in the command line.
   Use `pgrep -f 's[h]otloop'` and kill the PIDs.
6. **A gate that cannot go red is worse than a tool that lies.** Every gate added tonight
   (`death_reload.py`, `ghost_stamp.py`) had its control demonstrated red first. `ai_check`'s M3
   went red and turned out to be the liar — `arm()` zeroed `mon_kind`, so the fixture described
   creatures standing on water. Check the fixture before condemning the fix.
7. **Owner observation outranks my inference. Every single time tonight it did** — the frozen
   creatures, "there's no forest", "grass west, east and north of them", "the original doesn't
   have these ghosts", "towns/castles act the same as overworld", "they're definitely
   invulnerable". Each one I argued with first and each one was the bytes agreeing with him.
